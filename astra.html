در نسخه واقعی، این مرحله می‌تواند سفارش را در backend ثبت کند، پرداخت را آغاز کند و مشخصات طراحی را برای کارگاه ساخت ارسال کند.

Zarchi Astra در این prototype یک تجربه نمایشی است و به ChatGPT یا سرویس ساخت تصویر واقعی متصل نیست. برای production، prompt و generation باید از طریق backend امن به API هوش مصنوعی متصل شوند تا کلیدها در مرورگر افشا نشوند.
